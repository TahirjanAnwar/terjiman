Download Terjiman and run it, no Python needed:

- Windows 10 and 11: Terjiman.exe
- Mac with Apple Silicon (M1 and newer), macOS 11 and newer: Terjiman-mac-AppleSilicon.dmg
- Mac with Intel, macOS 10.15 Catalina and newer: Terjiman-mac-Intel.dmg

New in this version:
- Works on Mac too (in the menu bar, ⌘+Shift+Space opens the box)
- Free mode with Google Translate when you have no Claude key
- An update button in the box
- Terjiman's own icon on the taskbar

First start: Windows may say "Windows protected your PC": click More info, then Run anyway. On a Mac, see "Install on a Mac" in the README.
